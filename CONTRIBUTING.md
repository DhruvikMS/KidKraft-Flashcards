# Contributing

Thanks for your interest in KidKraft Flashcards.

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Install dependencies with `npm install`.
4. Run `npm run dev` locally.
5. Run `npm run check` before opening a pull request.
6. Keep changes focused and document meaningful behavior changes.

## Code style

Prefer small reusable React components, typed interfaces, semantic HTML, and accessible UI patterns. Avoid committing credentials, generated build output, or local environment files.
